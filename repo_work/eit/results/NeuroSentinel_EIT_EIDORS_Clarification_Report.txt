NEUROSENTINEL - EIT AND EIDORS CLARIFICATION REPORT
====================================================

Software-only research prototype using simulated EIT data. No clinical
tumour detection or recurrence prediction is established.

False positives: 0; false negatives: 0

3. DICE AND IOU INTERPRETATION
The validation script uses the known anomaly mask to determine the
number of predicted elements. It sorts reconstructed values in
ascending order and selects exactly that number of lowest-valued
elements. The predicted mask is compared with the known mask.
Therefore, Dice 1.0 and IoU 1.0 indicate exact overlap in this
known-size, same-mesh simulated localization procedure. They do not
demonstrate independent clinical detection or unknown-size estimation.

4. EIDORS CONFIGURATION
EIDORS 3.12; GNU Octave 11.3.0.
c2C model: 313 nodes, 576 elements.
d2C model: 545 nodes, 1024 elements.
The tested c2C forward model had no explicit coarse2fine field.
Inverse hyperparameter: 0.03.
RtR prior: eidors_default; registered default implementation:
prior_laplace.
The inspected Jacobian implementation was jacobian_adjoint. Its
coarse2fine support is conditional on that field being present.
An explicit mapping was not verified in the tested model.

The original noise-generation source script was not located.
Report these as archived experimental results with that limitation.

7. SOFTWARE-LEVEL SUCCESS CRITERIA
- Finite and dimension-consistent measurements.
- Consistent baseline, anomaly, and difference measurements.
- Finite reconstructed values.
- Documented mesh dimensions and element correspondence.
- Explicit localization selection rule and known-mask comparison.
- RMSE, MAE, Dice, and IoU reported together.
- Repeatability under identical configuration.
- Noise performance reported separately at each tested level.
These criteria concern software/simulation reproducibility, not
clinical validity.

8. LIMITATIONS
- Archived validation uses simulated EIT data only.
- No patient data or clinical validation were used.
- Perfect Dice/IoU depend on known anomaly size.
- Performance degrades at 5% and 10% noise.
- Original noise-generation script remains unlocated.
- Direct EIDORS cross-mesh element correspondence needs documentation.
- Archived simulation and direct EIDORS experiment are distinct.
